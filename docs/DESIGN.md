# 实际算法与实验边界（v1）

本系统独立实现“自回归破坏＋贪心修复基线”，并增加真实/打乱关系辅助监督。不依赖 NDS，不复刻其数值行为或性能。研究范围为一次删除序列内的条件依赖。由于动作顺序决定重插入顺序，关系组应称“关系辅助的删除及重插入顺序策略”；收益不能全部归于删除集合。

## 固定语义

| 项目 | 当前实现 |
|---|---|
| 数据 | JSON 显式导入；单一客户数与 distribution；depot=0，客户=1..N；路线不含 depot |
| 距离 | Python 双精度未取整欧氏距离；模型默认 float32；无坐标或需求分布转换 |
| 容量 | 非负需求、需求≤容量，depot 需求=0；可行路线载重≤容量；无车辆数量上限 |
| 当前解 | 必须提供 states.json；不从参考解生成学生当前解；同一数据目录供三组使用 |
| 删除 | 固定 k=destroy_size，1≤k≤N；依次选择不同客户；depot/已选节点 mask 为 -inf |
| 解码 | 编码当前完整解一次；GRU 累积已选节点顺序，pointer logits 选择下一节点；无额外 latent、dropout 或随机编码 |
| 修复 | 同时删除整个序列，去掉空路线，保留其余路线相对顺序；严格按动作序列逐个插入 |
| 插入规则 | 枚举全部既有路线所有位置（含两端），只接受容量可行候选，最小增量成本；精确浮点平局以路线序号、位置决胜 |
| 新路线 | 仅当所有既有路线均不可行才追加单客户路线；不把新路线当作一般竞争候选 |
| 反馈 | 每个完整序列只修复一次；r=(C_before−C_after)/max(C_before,1e-12)，不截断负收益 |
| baseline | K≥2 条独立采样 rollout 的 leave-one-out：b_k=Σ_{j≠k}r_j/(K−1)，与当前动作独立 |
| 主损失 | −mean_k[(r_k−b_k).detach() × Σ_t log π(a_t)]，全部 rollout 参与，非 top-1 |
| 状态训练 | 输入固定状态集合；每次更新对 batch 内每个不同实例随机取一个状态；不滚动更新当前解、不回传多轮回报 |
| 搜索 | 每轮重新编码当前解，采样一条序列并修复；仅严格成本改善时接受；无 SA、重启、latent、多解池 |
| 停止 | 固定迭代或单实例时间预算；时间模式把预处理/编码/解码/采样/修复/检查计入；最后超时完成的候选不计收益，报告超时量 |

初始 states 是独立输入，训练与评价均验证完整覆盖/成本；每组必须使用相同文件。库提供按客户编号贪心构造初始解的 helper，但 CLI 不自动把未知初始解规则混入实验。不存在自动数据下载或正式数据生成。

## 结构编码器与部署边界

每节点输入是 x、y、需求/容量、当前路线载重/容量、到 depot 距离、depot 标志。先线性投影，再进行当前路线邻居均值消息传递、同路线节点均值聚合，以及标准无 dropout self-attention/FFN。没有旧汇总 MLP、Point 候选或旧 checkpoint。路线编号仅用于集合相等判断，不作为数值特征。邻居聚合对路线反转对称，路线聚合对编号/排列不敏感。

策略 GRU 接上一选择节点的表示，初始状态来自客户表示均值；masked pointer 逐步采样。普通输入通过白名单函数投影，模型拒绝额外字段。关系头接确定性的共享编码器输出，输入 h_i+h_j 和 h_i*h_j，天然对称；标签不进入编码器或策略。

导出 policy.pt 仅保留编码器、策略参数、结构和来源身份，不包含关系头、标签、参考成本或参考路径。部署/评价不接受 --references。加载参考的唯一学习路径是训练/训练集关系诊断。神经损失、策略导出、恢复一致性测试须在已有 PyTorch 环境执行，不能用静态解析代替。

## 关系损失与对照

保留原数据契约：等权参考、客户无向相邻边、无 depot/对角；拒绝不足 M、失败或身份不匹配。默认保留重复等权并记录重复数，reject 策略不补跑。频率不是最优边概率；零频不是禁边；频率不能保留高阶组合。

L_relation 用每状态全部 i<j 客户对的无权 soft BCE，先按对均值，再按 batch 内不同实例均值。每个实例每次更新只取一个状态、计算一次辅助损失，不随 K 或 M 放大。没有正负重加权；仍不宣称 q 已校准。每次再次访问实例均再计一次关系损失；访问顺序由独立数据 RNG 决定。最后不足整批时用实际实例数均值，并记录真实 rollout 数。

A 基线 λ=0；B 真实关系 λ>0；C 固定客户置换 ΠPΠᵀ，只改标签、不改普通输入。所有组始终构建同一辅助头，初始化顺序相同。λ=0 不读取参考、不计算辅助分支，退化到本系统主损失路径，未声称与上游 NDS 等价。shuffle 保留图同构、对称性和权重直方图，破坏与客户几何/需求/当前解对应；允许固定点，不是完美因果对照。

主损失、辅助损失、主/辅共享编码器梯度范数、乘 λ 后的辅助范数、全梯度裁剪前范数逐步记录。训练期关系诊断以真实标签比较 soft BCE、Brier、训练集全局密度常数和当前邻接的 0.9/0.1 预测。shuffle 组诊断同样看真实关系；该诊断不参与 checkpoint 选择。

## 随机流、预算与恢复

初始化用保存/恢复的 CPU RNG 上下文；policy 采样用显式 CPU torch.Generator（GPU logits 转 CPU 后采样，开销计时）；数据/状态抽样用独立 random.Random；shuffle 用内容 hash 和独立 seed，无状态标签采样。不得强求更新后不同实验组轨迹一致。

正式步骤须 kind=experiment、budgets_confirmed=true、--confirm-real-run 三者同时成立。模板中的 null 必须填写，未指定研究预算不能启动。--synthetic 只接受每实例显式 synthetic=true 且 N≤12、实例数≤12、步数≤4、K≤4 等小上限。预算不是远程权限授权；仅由用户在服务器启动。

每个更新保存不可覆盖 checkpoint，含模型、Adam、累计 step、数据顺序/游标/epoch、数据 RNG、策略 RNG、Python/torch/CUDA RNG 和累计更新时间。manifest 先登记 attempted_step，成功保存 checkpoint/指标后登记 committed_step。恢复要求相同代码/配置/数据/状态/参考身份、torch 版本，并只能从源 run 最后已提交且无额外尝试的 checkpoint 恢复到新目录；总 steps 不重置。

保守失败策略：若进程在 attempt 登记之后失败，即使实际上未更新，自动恢复也拒绝，需人工核算损耗；不通过重试悄悄返还预算。每步 checkpoint 和梯度诊断较慢，当前优先可审计；训练更新吞吐和包含 checkpoint 的 session_seconds 分别记录。未实现中途自动续跑或评价自动恢复。

## 数据身份与评价

数据清单按实例分 train/validation/test。同一实例多个 states 挂在同一 ID 下；family_id 用于显式变体分组，同 family 跨 split 拒绝。内容 hash 规范化数值并排除 ID/split；同一内容重复直接拒绝。无法自动识别任意节点重编号/几何等价变体，必须提供一致 family_id。

训练只迭代 train；validation 仅做求解评价；测试要求匹配 config/data/states/policy 的 freeze.json，并带匹配验证集求解结果身份。当前 checkpoint 规则固定 last_step，不提供以关系准确率挑选 checkpoint。用户可在验证结果上比较预先计划的配置，再对所有组/seed 一并冻结，不能根据测试改配置。软件无法证明未报告的调参不存在，报告必须披露候选数。

评价输出逐实例/状态/seed/repeat 原始记录：单步 gain、概率与分布；固定迭代、等时间成本及改善事件 anytime trace。时间在一个已加载模型下按实例计时，模型加载作为离线启动开销；没有额外模型 warmup。文件落盘在搜索返回后，搜索内部计算和验证计入；首轮冷启动也计入。超时不可取消单个 Python/PyTorch 调用，只剔除迟到候选并报告超时墙钟。

compare 强制匹配数据、状态、训练/评价预算及 seed 行集合；先按实例平均所提供 seed/repeat，再按实例 bootstrap，同时报告每个训练 seed，不能挑最佳 seed。CI 不覆盖 seed 抽样不确定性或配置筛选偏差。当前提供描述统计与配对差，不自动把某个 p 值判作研究成功。

成功要求真实关系组在实际求解收益上稳定优于 A 和 C；预测提高但求解不提高须报告未转化。固定迭代只是诊断，不能替代等时间。参考生成成本单列，不能由环境交互/超参搜索预算掩盖。
